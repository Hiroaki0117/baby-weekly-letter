# 要求: 体温記録に時間区分を追加し、統計をグリッド表示に変更

## 背景

現在の統計画面の「体温の推移」は折れ線グラフで時系列表示しているが、1日の中で朝・昼・夕・夜にどう変化したかを振り返りにくい。
食事や睡眠と同様に、日×時間区分のグリッド表示にすることで一目で傾向を把握できるようにしたい。

## 要求内容

- `temperature_records` テーブルに `temp_period` カラムを追加し、計測時刻から自動判定して保存する
- 統計画面の体温チャートを日×時間区分のグリッド表示に変更する
- 同じ時間区分に複数回計測がある場合、セルには最新の1件を表示し、ホバー/タップで全件を表示する

## 判定ルール

計測時刻は日本時間（JST / UTC+9）で判定する。

- **朝 (`morning`)**: 5:00〜9:59 (JST)
- **昼 (`afternoon`)**: 10:00〜15:59 (JST)
- **夕 (`evening`)**: 16:00〜19:59 (JST)
- **夜 (`night`)**: 20:00〜翌4:59 (JST)

## 受け入れ条件

- [ ] `temperature_records` テーブルに `temp_period` カラム（`morning` / `afternoon` / `evening` / `night`）が追加される
- [ ] マイグレーションで既存レコードにも `measured_at` から自動判定して値がセットされる
- [ ] 体温記録の登録・更新時に `measured_at` から `temp_period` が自動セットされる
- [ ] 統計チャートが日×時間区分（朝・昼・夕・夜）のグリッド表示になる
- [ ] セルに体温の数値を表示し、37.5℃以上は赤系の色で強調する
- [ ] 同一区分に複数記録がある場合、ホバー/タップで全件表示できる
- [ ] 判定ロジックのユニットテストがある

## 制約事項

- 入力 UI での区分選択は不要（自動判定のみ）
- 将来的にユーザーが区分を手動変更できる拡張を想定し、カラムとして保持する
