# v3.6 記録リマインダー - 要求内容

## 概要

その日の育児記録がない場合に、PWA Web Push通知でリマインダーを送信する。記録の習慣化を促進する。

## ユーザーストーリー

> 育児中の親として、日記を書き忘れた日に通知してほしい。それにより、記録の習慣を維持したい。

## 機能要件

### 通知手段

- PWA Web Push通知を使用する
- ブラウザのPush APIとService Workerで実現する
- 対応ブラウザ: Chrome, Edge, Firefox, Safari（iOS 16.4+）

### 通知タイミング

- 毎日 **21:00 JST** に固定
- 時刻のカスタマイズは不可（将来対応の余地あり）

### 通知条件

- その日（JST基準）の `daily_logs` テーブルに、**家族の誰の記録もない**場合に通知する
- 家族内の誰か1人でも記録していれば、全メンバーに通知しない
- 通知が有効（オプトイン済み）のユーザーのみ対象

### 通知内容

- タイトル: 「すくすく日記」
- 本文: 「今日の記録がまだありません。今日の出来事を残しましょう！」（1パターン固定）
- タップでアプリの「今日」ページに遷移

### オプトイン/アウト

- **新規ユーザー**: 初回ログイン後にダイアログを表示し、通知許可を求める
- **既存ユーザー**: 機能リリース後の次回アクセス時に1回だけダイアログを表示
- ダイアログで「許可しない」を選んだ場合、再表示しない
- 設定画面からいつでもON/OFFを切り替え可能

### バックエンド

- **Next.js Route Handler** で通知送信ロジックを実装（`/api/cron/send-reminders`）
- **GitHub Actions** の schedule トリガーで毎日21:00 JST（UTC 12:00）にRoute Handlerを呼び出す
- Web Push用のVAPIDキーをVercel環境変数で管理
- Push Subscriptionはデータベースに保存
- Route HandlerはCRON_SECRETヘッダーで不正呼び出しを防止

## 受け入れ条件

- [ ] 通知許可ダイアログが初回ログイン時（または既存ユーザーの次回アクセス時）に表示される
- [ ] 「許可」を選択するとPush Subscriptionが保存される
- [ ] 21:00 JSTに家族の記録が0件の場合、許可済みユーザーにPush通知が届く
- [ ] 家族の誰かが記録済みの場合、通知が届かない
- [ ] 通知タップでアプリの「今日」ページが開く
- [ ] 設定画面から通知のON/OFFを切り替えられる

## 制約事項

- iOS Safari は16.4以降でWeb Pushに対応。それ以前のiOSでは通知不可（ダイアログ非表示で対応）
- GitHub Actions のcronは数分のずれが発生する場合がある（正確に21:00ではない可能性）
- Supabase無料プランを使用（Edge Functions・pg_cronは使用しない）
