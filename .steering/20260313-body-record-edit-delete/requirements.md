# 要求: 体温・睡眠・食事記録の編集・削除機能

## 背景

体温・睡眠・食事の記録を登録した後に、編集や削除ができない。
値を間違えた場合や不要な記録を消したい場合に対応できない。

## 変更内容

統計チャートの週別表示のポップオーバーに削除ボタン、レコードタップで編集用ボトムシートを追加。

### 削除
- 週別ポップオーバー内の各レコード横にゴミ箱アイコンを表示
- タップ → 確認ダイアログ → 削除実行 → UIから即時反映

### 編集
- ポップオーバー内のレコードをタップ → ボトムシートが開く
- 体温: 体温値・計測時刻を編集
- 睡眠: 開始時刻・終了時刻を編集
- 食事: 食事量(amount)を編集
- 保存 → UIから即時反映

## 受け入れ条件

- 体温・睡眠・食事の各チャート（週別）で、ポップオーバー内レコードの削除ができる
- 体温・睡眠・食事の各チャート（週別）で、レコードをタップして編集ボトムシートが開く
- 編集・削除後にチャートデータが即時反映される（再フェッチ）
- 月別カレンダーのポップオーバーでも同じ操作が可能
