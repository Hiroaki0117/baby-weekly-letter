# モバイルレイアウト修正 要求定義

## 背景・課題

スマホで閲覧した際にレイアウトが崩れているという問題が報告された。
Webインターフェースガイドラインに基づく全ファイル監査を実施し、以下の重大な問題を特定した。

## 発見された問題

### 重大（表示崩れ）
1. **ヘッダーのオーバーフロー**: 5ナビリンク + ロゴ + 設定アイコン + ログアウトボタンが h-14 のヘッダーに収まらない
2. **MoodSelector のオーバーフロー**: 5ボタン × 固定 80px + gap = 448px 最小幅。iPhone SE（375px）でビューポートをはみ出す

### 重大（タッチ操作不可）
3. **LogCard 編集/削除ボタンが不可視**: `opacity-0 group-hover:opacity-100` はタッチ端末では機能しない
4. **写真削除ボタンが小さすぎる**: `h-6 w-6`（24px）はタッチ不可能

### 中（アクセシビリティ・UX）
5. **ナビタッチターゲット不足**: `px-2.5 py-1.5` ≈ 24px（推奨 44px を大幅に下回る）
6. **カレンダーセルのタッチターゲット**: `py-1.5` のみで正確なタップが困難

## ユーザー要件

- スマホでの閲覧時にレイアウトが正しく表示されること
- モバイルナビゲーションパターン: **ボトムタブバー**（ユーザーが選択）
- タッチターゲットが 44px 以上であること
- 編集・削除操作がモバイルでも可能であること

## 受け入れ条件

- [ ] iPhone SE（375px幅）でヘッダーがオーバーフローしない
- [ ] ボトムタブバーが表示され、全ナビ項目にアクセスできる
- [ ] MoodSelector が折り返しまたはレスポンシブサイズで正しく表示される
- [ ] LogCard の編集・削除ボタンがモバイルで表示される
- [ ] カレンダーセルのタッチターゲットが 44px 以上
- [ ] デスクトップ表示は従来通り（ヘッダーナビ、hover動作）
