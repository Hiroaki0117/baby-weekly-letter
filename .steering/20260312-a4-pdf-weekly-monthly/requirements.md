# 要求内容：週次・月次アルバムのA4 PDF最適化

## 概要

週次・月次アルバムのPDFエクスポートを、A4用紙に最適化されたレイアウトで出力できるようにする。印刷して綴じればアルバムになる体験を提供する。

## 要件

### 週次アルバム A4 PDFレイアウト（1ページ）

| 領域 | 内容 | 高さ目安 |
|------|------|---------|
| 上部 | エアメールストライプ + 日付ヘッダー（Weekly Letter / 日付範囲）+ スタンプ風ロゴ | ~100px |
| 中央 | エッセイ本文（便箋風の罫線背景） | ~700px |
| 下部 | 写真グリッド（最大6枚） | ~280px |
| フッター | 「すくすく日記」ブランド | ~40px |

- 現状のエッセイ文字数（500〜800字）はA4 1ページに十分収まる
- 写真が7枚以上ある場合は最新6枚に制限

### 月次アルバム A4 PDFレイアウト（1ページ）

| 領域 | 内容 | 高さ目安 |
|------|------|---------|
| 上部 | グラデーションバー + 月ヘッダー（Monthly Album / 年月）+ スタンプ風ロゴ | ~100px |
| 中央 | エッセイ本文（便箋風の罫線背景） | ~700px |
| 下部 | 写真グリッド（最大6枚） | ~280px |
| フッター | 「すくすく日記」ブランド | ~40px |

### 共通仕様

- A4サイズ: 794px × 1123px（96dpi相当）、パディング40px
- 年次アルバムの `AnnualPdfLayout` と同じアプローチ（固定サイズDOM → `exportAsA4Pdf`）
- 既存の `ExportLayout` は PNG エクスポート用として残す（従来通り動作）
- PDFエクスポート時のみ新しいA4レイアウトを使用

## 受け入れ条件

- [ ] 週次アルバムのPDFがA4 1ページに最適化されて出力される
- [ ] 月次アルバムのPDFがA4 1ページに最適化されて出力される
- [ ] PNGエクスポートは従来通り動作する
- [ ] 印刷時に余白なくきれいに収まる
