# v2.3 統計ダッシュボード - 要求定義

## 概要

記録データを可視化し、育児の傾向と成長を実感できる統計ダッシュボードを `/stats` に新規追加する。
併せてナビゲーションを再構成し、家族をナビから外して統計を追加する。

## ユーザーストーリー

> 育児中の親として、日々の記録を月別のグラフで確認したい。
> それにより、子どもの成長傾向を客観的に実感し、記録を続けるモチベーションにしたい。

## 機能要件

### 1. ナビゲーション再構成

- ナビ項目を以下の5つに変更:
  - 今日 / カレンダー / 記録 / 写真 / 統計
- 「家族」をナビから外し、ヘッダーのアイコン（設定の隣）に移動
- PC版・スマホ版（ボトムバー）ともに同じ構成

### 2. 統計ダッシュボード（`/stats`）

以下の3つのグラフを1ページに縦に並べて表示する。

#### 2.1 月別記録数（棒グラフ）

- X軸: 月（YYYY/MM）
- Y軸: 記録件数
- 全期間のデータを表示

#### 2.2 気分の推移（積み上げ棒グラフ）

- X軸: 月（YYYY/MM）
- Y軸: 件数
- 5つの気分（moved / happy / neutral / tired / sad）を色分けして積み上げ
- 凡例を表示

#### 2.3 カテゴリ別記録割合（円グラフ）

- 全期間のカテゴリ別記録数を円グラフで表示
- カテゴリ名と件数を凡例に表示

### 3. 子ども切り替え

- 複数の子どもがいる場合、ページ上部にタブを表示して切り替え
- 子どもが1人の場合はタブを非表示

## 技術要件

- チャートライブラリ: Recharts
- データ集計: クライアントサイドでログデータを集計（サーバーサイドの集計APIは不要）
- レスポンシブ: スマホ・PC両対応

## 受け入れ条件

- [ ] `/stats` ページにアクセスできる
- [ ] ナビに統計が表示され、家族がヘッダーに移動している
- [ ] 月別記録数の棒グラフが表示される
- [ ] 気分の推移が積み上げ棒グラフで表示される
- [ ] カテゴリ別割合が円グラフで表示される
- [ ] 複数子供の場合、タブで切り替えできる
- [ ] 記録がない場合、空状態メッセージが表示される
- [ ] lint / type-check / test が通る

## 制約事項

- 期間の切り替え機能は不要（全期間のみ）
- データエクスポート機能は含めない
