# メニュー構成の再編成 - 要求内容

## 背景

現在のメニュー構成は機能の所在がわかりにくい。

- 「記録」メニューの中にアルバムや写真が含まれていて直感に合わない
- 「統計」という名前が堅い
- カレンダーと記録の一覧は同じデータを表示しており、入口が分かれている必要がない

## 変更概要

### メニュー構成の変更

#### 現状

**PC版ヘッダー（nav.tsx）:** 今日 / カレンダー / 記録 / 写真 / 統計（5項目）
**スマホ版ボトムナビ（bottom-nav.tsx）:** 今日 / カレンダー / 記録 / 統計 / その他（5項目）

#### 変更後

**PC版ヘッダー:** 今日 / 日記 / アルバム / レポート（4項目）
**スマホ版ボトムナビ:** 今日 / 日記 / アルバム / レポート / その他（5項目）

### 各メニューの中身

#### 今日（変更なし）
- 日々の記録入力、今日のログ表示、クイック入力（体温・睡眠・食事）

#### 日記（旧：カレンダー + 記録 → 統合）
- カレンダー表示と記録一覧を同じページ内で切り替えられるようにする
- カレンダー表示: 現状の `/calendar` の機能
- 一覧表示: 現状の `/logs?tab=logs` の機能（フィルター含む）

#### アルバム（旧：記録内の写真・アルバムタブを独立）
- 写真ギャラリー: 現状の `/logs?tab=photos` の機能
- 週次アルバム: 現状の `/logs?tab=weekly` の機能
- 月次アルバム: 現状の `/logs?tab=monthly` の機能
- 年次アルバム: 現状の `/logs?tab=annual` の機能
- レポート設定: 現状の `/logs?tab=report-settings` の機能

#### レポート（旧：統計 → 名前変更）
- 記録タブ: 気分チャート、カテゴリ分布（現状の統計 - 記録タブの機能）
- からだの記録タブ: 成長曲線、体温・睡眠・食事の推移グラフ + 編集・削除（現状の統計 - からだの記録タブの機能）

## 受け入れ条件

- PC版ヘッダーのメニューが「今日 / 日記 / アルバム / レポート」の4項目になっている
- スマホ版ボトムナビのメニューが「今日 / 日記 / アルバム / レポート / その他」の5項目になっている
- 「日記」ページでカレンダー表示と一覧表示を切り替えられる
- 「アルバム」ページで写真・週次・月次・年次・設定のタブが表示される
- 「レポート」ページは現状の統計ページと同じ機能が使える
- 旧URL（`/calendar`, `/logs`, `/gallery`, `/stats`）からのリダイレクトが機能する
- 既存の機能が欠落なく動作する

## 制約事項

- ページの中身（コンポーネント）は既存のものを流用し、新規作成は最小限にする
- URL構造の変更に伴い、既存のリダイレクト（`/gallery` → `/logs?tab=photos`, `/weekly` → `/logs?tab=weekly`）も新URLに更新する
