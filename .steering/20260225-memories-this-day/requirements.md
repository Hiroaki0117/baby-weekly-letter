# 要求定義: 過去の振り返り（○年前の今日）

## 背景

v2 ロードマップ優先度2の機能。ホーム画面に「○年前の今日」の記録を表示し、成長の実感と感動を提供する。長期利用のリピート動機になる。

## ユーザーストーリー

> 育児中の親として、アプリを開いたときに「1年前の今日はこんなことがあったんだ」と写真付きで振り返りたい。それにより、子どもの成長を実感し、記録を続けるモチベーションにしたい。

## 要件

### 表示場所

- ホーム画面の日付カードとログフォームの間に配置

### 表示条件

- 1年以上前の同月同日にログが存在する場合のみ表示
- 該当ログがなければセクション自体を非表示
- 複数年分（1年前、2年前…）がある場合はすべて表示（新しい順）
- 同じ年の同日に複数ログがある場合もすべて表示

### 表示内容

- 年ラベル（「1年前の今日」「2年前の今日」）
- 日付（「2025年2月25日」）
- 写真（ある場合はカード上部に大きく表示）
- テキスト（ログ本文）
- 気分スタンプ
- カテゴリバッジ
- 子供バッジ（複数子供の場合のみ）

### データソース

- 既存の `daily_logs` テーブルから `log_date` で過去の同月同日を取得
- 新規テーブルは不要

## 受け入れ条件

- [ ] ホーム画面に「○年前の今日」セクションが表示される
- [ ] 1年以上前の同日にログがない場合はセクションが非表示
- [ ] 写真付きログはカード上部に写真を大きく表示
- [ ] 複数年分の記録がすべて表示される
- [ ] 複数子供の場合、子供バッジが表示される
- [ ] lint / type-check / test がすべてパスする
