# 年次アルバム自動生成 - 要求内容

## 概要

1年間（年度: 4月〜3月）の育児記録から、AIで年間ダイジェストを自動生成し、PDFとして出力する。月ごとのハイライト文・写真・マイルストーン・成長データを含む、振り返り用のアルバム。

## ユーザーストーリー

> 育児中の親として、1年分の記録からAIで年間ダイジェストを自動生成したい。それにより、1年の成長を一冊のアルバムとして振り返りたい。

## 背景・課題

- 週次通信・月次まとめで細かい振り返りはできるが、1年の全体像を俯瞰するコンテンツがない
- 保育園の進級時や誕生日のタイミングで「この1年どうだったか」を振り返りたいニーズがある
- 祖父母や家族にまとめて共有できるPDFがあると喜ばれる

## 機能要件

### 対象期間

- **年度単位**: 4月1日〜翌年3月31日
- ユーザーが対象年度を選択して生成（例: 「2025年度」= 2025/4/1〜2026/3/31）
- 対象年度にデータがない場合は生成不可（エラーメッセージ表示）

### 生成可能タイミングとクールダウン

- **生成可能時期**: 対象年度の最終月（3月）以降いつでも生成可能
  - 例: 2025年度アルバムは2026年3月1日以降に生成可能
  - 過去年度もいつでも生成・再生成できる
  - 3月以前（4月〜2月）はデータが揃っていないため生成ボタンを非活性にする
- **クールダウン**: 前回生成から24時間は再生成不可
  - `generated_at` と現在時刻の差分で判定
  - 生成ボタンに「○時間後に再生成可能」と表示
  - 年度・子供の組み合わせごとにクールダウンを管理

### アルバムのコンテンツ構成

1. **表紙**: 子供の名前、対象年度、「○歳の記録」（年度開始時の年齢）
2. **月ごとのページ**（最大12ページ: 4月〜3月）
   - 月のハイライト文（AI生成: その月の週次通信・月次まとめから1〜2文で要約）
   - 月のベスト写真（その月の最後に登録された写真を1枚選出。写真がない月はプレースホルダー）
3. **マイルストーンまとめ**: 1年間の「初めて○○した」を時系列リストで掲載
4. **成長データサマリー**: 身長・体重の年度開始時→年度終了時の変化（データがあれば）
5. **1年の総括メッセージ**: AI生成の感動的な締めの文章（3〜5文）

### テキスト生成

- Route Handler 経由で Gemini API を呼び出し
- 入力データ: 対象年度の週次通信・月次まとめ・マイルストーン・成長データ
- 週次通信カスタマイズのトーン設定を反映
- 出力: 月ごとのハイライト文（12件）+ 1年の総括メッセージ

### 写真選出

- 各月の `daily_logs` から `photo_storage_path` が存在するレコードを `log_date` 降順で取得し、最初の1枚を選出
- 写真がない月はスキップ（またはプレースホルダー表示）

### 出力形式

- PDF（A4縦、複数ページ）
- クライアントサイドで `html-to-image` + `jsPDF` を使用（既存のエクスポート機能と同じ方式）
- アルバム専用のレイアウトコンポーネントで構成

### 画面配置

- 記録一覧画面（`/logs`）の既存タブ（ログ・週次・月次）に「年次」タブを追加
- 年次タブ: 生成済みアルバム一覧 + 「年次アルバムを作る」ボタン
- 年度・子供を選択して生成

### データ保存

- 生成結果を `annual_reports` テーブルに保存（再生成は上書き）
- PDFはオンデマンド生成（DB保存はテキストのみ）

## 受け入れ条件

- [ ] 記録一覧に「年次」タブが表示される
- [ ] 年度と子供を選択して「年次アルバムを作る」ボタンで生成できる
- [ ] 月ごとのハイライト文がAI生成されてアルバムに含まれる
- [ ] 各月の最新写真がアルバムに含まれる
- [ ] マイルストーンが時系列リストで掲載される
- [ ] 成長データ（身長・体重）のサマリーが含まれる（データがある場合）
- [ ] 1年の総括メッセージがAI生成される
- [ ] PDFダウンロードができる
- [ ] 同一年度・同一子供で再生成すると上書き保存される
- [ ] 対象年度にデータがない場合はエラーメッセージが表示される

## 制約事項

- Gemini API への送信データ量が大きくなる可能性がある（12ヶ月分の通信データ）。トークン上限に注意
- PDF生成はクライアントサイドのため、低スペック端末では時間がかかる場合がある
- 写真のない月は月ハイライト文のみの表示になる
