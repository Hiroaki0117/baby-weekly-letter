# 体温クイック入力 + PWAショートカット - 要求内容

## 概要

今日ページから体温をすばやく記録できるクイック入力UIを追加する。あわせてPWAショートカットで家族ページへの直行リンクを設定する。

## ユーザーストーリー

> 育児中の親として、アプリを開いたらすぐに体温を入力したい。家族ページまで移動するのは手間がかかる。

## 機能要件

### 案1: 今日ページのクイック体温入力

- 今日ページの**ストリーク表示の下、日記入力フォームの上**に配置
- **折りたたみ式UI**: 通常は「体温を記録」バーのみ表示。タップすると入力欄が展開
- 展開時に**全子供分の入力欄**を並べて表示（子供名 + 体温入力 + 記録ボタン）
- 子供が1人の場合は子供名のみ表示（セレクターなし）
- 入力後は成功トーストを表示し、入力欄をクリア
- 既存の `addTemperatureRecord` 関数を使用してDBに保存

### 案2: PWAショートカット

- `manifest.webmanifest` に `shortcuts` を追加
- 「体温を記録」ショートカット → 家族ページ（`/family`）に遷移
- ホーム画面のアイコン長押しで表示される

## 受け入れ条件

- [ ] 今日ページを開くと、日記フォームの上に「体温を記録」バーが表示される
- [ ] バーをタップすると全子供分の体温入力欄が展開される
- [ ] 体温を入力して記録ボタンを押すとDBに保存される
- [ ] 記録後にトーストが表示され入力欄がクリアされる
- [ ] PWAホーム画面アイコン長押しで「体温を記録」ショートカットが表示される

## 制約事項

- PWAショートカットはホーム画面に追加済みの場合のみ有効
- 既存の体温記録機能（家族ページ）はそのまま維持
