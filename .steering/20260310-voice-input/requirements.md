# 音声入力 - 要求内容

## 概要

ホーム画面の日記入力フォームにマイクボタンを追加し、音声で日記を入力できるようにする。Web Speech API を使用してブラウザ内でリアルタイムに文字起こしし、テキスト欄に直接挿入する。

## ユーザーストーリー

> 育児中の親として、話すだけで日記を入力したい。それにより、両手がふさがっていても記録を残せるようにしたい。

## 背景・課題

- 授乳中・寝かしつけ中など、両手がふさがる場面が多い
- スマホでのタイピングは片手だと時間がかかり、記録を諦めてしまう
- 音声なら話すだけで記録でき、入力のハードルが大幅に下がる

## 機能要件

### 音声入力

- テキスト入力欄の右端にマイクボタン（🎤）を配置
- マイクボタンタップで録音開始。ボタンが録音中状態（赤色 + アニメーション）に変わる
- 音声をリアルタイムで文字起こしし、テキスト欄に直接挿入する
- 再度マイクボタンをタップ、または一定時間の無音で自動停止
- テキスト欄に既存テキストがある場合は末尾に追記する
- 録音中はテキスト欄にリアルタイムで仮テキストが表示される（Web Speech API の interim results）

### 技術仕様

- **文字起こしエンジン**: Web Speech API（SpeechRecognition）
- **言語設定**: `ja-JP`（日本語）
- **サーバーサイド処理**: 不要（ブラウザ内で完結）
- **追加コスト**: なし

### ブラウザ対応

- **対応**: Chrome、Edge、Safari（Web Speech API サポートあり）
- **非対応ブラウザ**: マイクボタンを非表示にする（通常のテキスト入力は引き続き利用可能）
- `window.SpeechRecognition || window.webkitSpeechRecognition` の存在チェックで判定

### 対象画面

- ホーム画面（今日のログ入力フォーム）
- ログ編集画面（既存ログの編集時）

## 受け入れ条件

- [ ] ホーム画面のテキスト入力欄にマイクボタンが表示される（対応ブラウザのみ）
- [ ] マイクボタンタップで録音が開始され、ボタンが録音中の見た目に変わる
- [ ] 話した内容がリアルタイムでテキスト欄に反映される
- [ ] 再度タップまたは無音で録音が停止する
- [ ] 既存テキストがある場合は末尾に追記される
- [ ] 非対応ブラウザではマイクボタンが表示されない
- [ ] ログ編集画面でも同様に音声入力が使える
- [ ] マイク権限の拒否時にエラーメッセージが表示される

## 制約事項

- Web Speech API はオンライン接続が必要（オフラインでは動作しない）
- 認識精度はブラウザ・デバイスに依存する
- iOS Safari では Web Speech API の挙動に制限がある場合がある（実機テストで確認）
