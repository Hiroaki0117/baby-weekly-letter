# 要求定義: マイルストーンとログの紐付け・閲覧改善

## 背景

v3.3で成長タイムライン機能を実装し、直後にマイルストーン入力をログフォームに統合した。
しかし現状、以下の課題がある:

1. マイルストーンとログがDB上で紐付いていない（`daily_log_id` カラムがない）
2. ログカードを見てもマイルストーンが登録されているか分からない
3. マイルストーンを一覧で見返す場所がない（統計ページから削除済み）

## 要求内容

### R-1: milestonesテーブルにdaily_log_idカラムを追加

- `milestones` テーブルに `daily_log_id` (uuid, nullable, FK → daily_logs) を追加
- ログフォームからマイルストーン保存時に、作成したログのIDを `daily_log_id` に設定
- AI抽出マイルストーンや過去分は `daily_log_id = null` のまま（既存データへの影響なし）

### R-2: ログカードにマイルストーンバッジを表示

- `LogCard` コンポーネントで、そのログに紐づくマイルストーンがある場合にバッジ表示
- 表示内容: マイルストーンのタイトル（例: 「✨ 初めて寝返りした」）
- カテゴリバッジの近くに配置し、視覚的に区別できるようにする
- 今日ページ・カレンダーページ・記録ページすべてで表示

### R-3: 統計ページ成長タブに小項目タブを追加

- 成長タブ内に「身長・体重」「初めての出来事」の2つの小項目タブを設ける
- 「身長・体重」: 既存の成長曲線グラフ（GrowthChart）をそのまま表示
- 「初めての出来事」: マイルストーンタイムラインを表示（カテゴリフィルタ・編集・削除機能付き）

## 制約事項

- DBマイグレーションはSupabaseダッシュボードから手動実行（本実装ではTypeScript型定義の更新のみ）
- 既存のマイルストーンデータ（`daily_log_id = null`）はそのまま動作すること
- ログ削除時のマイルストーン連動は今回スコープ外（マイルストーンは独立して残る）
