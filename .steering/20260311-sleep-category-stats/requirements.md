# 要求: 睡眠統計に日中/夜間の区分表示を追加

## 背景

現在の統計画面の「睡眠時間の推移」は1日あたりの合計睡眠時間のみを棒グラフで表示している。
乳幼児は昼寝と夜間睡眠のバランスが成長とともに変化するため、日中と夜間を分けて振り返れるようにしたい。

## 要求内容

- 統計画面の睡眠チャートを「夜間睡眠」「日中睡眠」に分けて表示する
- 区分はユーザーに選ばせず、睡眠開始時刻（`started_at`）から自動判定する
- `sleep_records` テーブルに `sleep_category` カラムを追加し、登録時に判定結果を保存する
- 統計表示時は保存済みの `sleep_category` を参照するだけで済むようにする

## 判定ルール

開始時刻は日本時間（JST / UTC+9）で判定する。

- **夜間睡眠 (`night`)**: 開始時刻が 19:00〜翌5:59 (JST)
- **日中睡眠 (`daytime`)**: 開始時刻が 6:00〜18:59 (JST)

## 受け入れ条件

- [ ] `sleep_records` テーブルに `sleep_category` カラム（`night` / `daytime`）が追加される
- [ ] マイグレーションで既存レコードにも `started_at` から自動判定して値がセットされる
- [ ] 睡眠記録の登録・更新時に `started_at` から `sleep_category` が自動セットされる
- [ ] 睡眠チャートが夜間/日中の積み上げ棒グラフで表示される
- [ ] 凡例で夜間・日中が区別できる
- [ ] ツールチップで夜間・日中それぞれの時間が表示される
- [ ] 判定ロジックのユニットテストがある

## 制約事項

- 入力 UI での区分選択は不要（自動判定のみ）
- 将来的にユーザーが区分を手動変更できる拡張を想定し、カラムとして保持する
