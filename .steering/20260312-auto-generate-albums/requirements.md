# 要求内容：アルバム自動生成 + アプリ内通知

## 概要

週次・月次・年次アルバムを、ユーザーが手動で作成しなくても自動的に生成する機能を追加する。自動生成されたアルバムがある場合は、ホーム画面にアプリ内通知を表示する。

## ユーザーストーリー

- 忙しくてアルバム作成を忘れていても、自動で週次アルバムが作られていてほしい
- 月次アルバムも自動で作成されてほしい
- 年次アルバムも年度末に自動で作成されてほしい
- 自動生成されたら、アプリを開いたときに気づけるようにしたい
- 自動生成が不要なら設定でオフにしたい

## 要件

### 1. 自動生成スケジュール

1つの Vercel Cron エンドポイント（`/api/cron/auto-generate`）で全種類を処理する。
Vercel 無料プランの cron 上限 2 枠のうち 1 枠のみ使用。

| 種類 | 実行条件 | タイミング |
|------|---------|-----------|
| 週次 | 毎週日曜 19:00 JST | 当該週のログが3件以上 & 未生成 |
| 月次 | 毎月末日 19:00 JST | 当月の週次アルバムが1件以上 & 未生成 |
| 年次 | 3月31日 19:00 JST | 年度内の月次アルバムが1件以上 & 未生成 |

- 毎日 19:00 JST に cron を実行し、エンドポイント内で当日が該当する処理を判定する
- 月末日かつ日曜の場合は、週次 → 月次の順で実行する
- 3月31日は、週次 → 月次 → 年次の順で実行する

### 2. 自動生成の条件

#### 週次アルバム
- 対象の週（月曜〜日曜）に当該子供のログが **3件以上** あること
- 同じ `(family_id, child_id, week_start)` で既に生成済みでないこと

#### 月次アルバム
- 当月の週次アルバムが **1件以上** 存在すること
- 同じ `(family_id, child_id, month)` で既に生成済みでないこと

#### 年次アルバム
- 年度内の月次アルバムが **1件以上** 存在すること
- 同じ `(family_id, child_id, fiscal_year)` で既に生成済みでないこと
- `canGenerate(fiscalYear)` が true（年度末の3月以降）

### 3. 自動生成設定

- `report_preferences` テーブルに `auto_generate` カラム（boolean, デフォルト true）を追加
- アルバム設定画面にオン/オフ切り替えを追加
- **デフォルト: オン（有効）**

### 4. アプリ内通知

- `notifications` テーブルを新設
- 自動生成が完了したら通知レコードを挿入
- ホーム画面で未読の自動生成通知を表示
- 通知をタップすると該当アルバムに遷移し、既読にする

### 5. cron 認証

- Vercel Cron は `CRON_SECRET` 環境変数による認証が推奨
- `Authorization: Bearer <CRON_SECRET>` ヘッダーでリクエストを検証

## 受け入れ条件

- [ ] 毎日 19:00 JST に cron が実行される
- [ ] 日曜日に週次アルバムが自動生成される（ログ3件以上の場合）
- [ ] 月末日に月次アルバムが自動生成される（週次アルバム1件以上の場合）
- [ ] 3月31日に年次アルバムが自動生成される（月次アルバム1件以上の場合）
- [ ] 自動生成後、ホーム画面に通知が表示される
- [ ] 通知タップで該当アルバムに遷移する
- [ ] アルバム設定で自動生成のオン/オフを切り替えられる
- [ ] デフォルトはオン
- [ ] Vercel Cron 枠を 1 つだけ使用する
- [ ] cron エンドポイントが CRON_SECRET で認証される

## 制約事項

- Vercel 無料プランの cron 上限は **2 枠**。本機能で 1 枠使用
- cron の最小間隔は 1 日 1 回（無料プラン）
- 自動生成は既存の生成ロジック（Gemini API 呼び出し）を再利用する
- 家族内の全子供に対して自動生成を実行する（ユーザーごとではなく家族単位）
