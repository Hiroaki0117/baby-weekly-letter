# 週次通信カスタマイズ - 要求定義

## 概要

週次・月次通信の生成時に、ユーザーごとの好みに合わせた文体（トーン）とセクション構成を反映する機能を追加する。

## ユーザーストーリー

> 育児中の親として、通信の文体やセクション構成を自分好みに設定したい。
> それにより、毎回の通信が自分にとって読みやすく、愛着の湧くものになるようにしたい。

## 機能要件

### 1. トーン設定

ユーザーが以下の4種類から文体トーンを1つ選択できる。

| トーン | 説明 | プロンプトへの影響 |
|--------|------|-------------------|
| ほっこり系（デフォルト） | 温かみのある手紙調 | 現状のプロンプトを維持 |
| ユーモア系 | 明るくユーモアを交えた文体 | 文体ガイドラインを差し替え |
| 淡々記録系 | 落ち着いた客観的なトーン | 文体ガイドラインを差し替え |
| ポエム系 | 詩的で情緒豊かな文体 | 文体ガイドラインを差し替え |

### 2. セクション構成設定

ユーザーが通信に含めるセクションをON/OFFで選択できる。

| セクション | 説明 | デフォルト |
|-----------|------|-----------|
| 今週のハイライト | 印象的なエピソードを1つ深掘り | ON |
| 日々のダイジェスト | 各日の出来事を短くまとめ | ON |
| 成長メモ | 前回と比較した変化 | ON |
| 親へのひとこと | 書き手（親）への労いの言葉 | OFF |
| 今週の名言 | ログから印象的な一言を引用 | OFF |

### 3. 設定の保存単位

- **ユーザー単位**で保存する
- 同じ家族内でもパパとママで異なるトーン・構成を設定できる

### 4. 設定UIの配置

- 既存の `/settings` ページに「通信設定」セクションを追加する
- PC版・モバイル版共通で `/settings` からアクセスする

### 5. 適用範囲

- **週次通信**と**月次通信**の両方に同じ設定を反映する

## 受け入れ条件

- [ ] 設定ページでトーンを4種類から選択でき、保存できる
- [ ] 設定ページでセクション構成を5種類のON/OFFで選択でき、保存できる
- [ ] 週次通信生成時に、生成を実行したユーザーの設定がプロンプトに反映される
- [ ] 月次通信生成時にも同じ設定が反映される
- [ ] 設定未保存（初回）の場合はデフォルト値で生成される
- [ ] 設定変更後、次回の生成から反映される（過去の通信には影響しない）

## 制約事項

- 通信の再生成時にも現在の設定が使われる
- セクションをすべてOFFにすることはできない（最低1つはON）
