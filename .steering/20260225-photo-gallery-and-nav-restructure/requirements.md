# 要求定義: 写真ギャラリー + ナビ構成変更

## 背景

v2 ロードマップの最優先機能として写真ギャラリーを実装する。同時に、将来の統計ダッシュボード追加を見据えてナビゲーション構成を整理する。

## 実装スコープ

本タスクでは以下の3つの変更をまとめて実施する。

### 1. 写真ギャラリーページの新規作成

記録に添付された写真を一覧で振り返れる専用ページ。

#### ユーザーストーリー

> 育児中の親として、過去に記録した写真を月別に一覧で見たい。それにより、子どもの成長を視覚的に振り返りたい。

#### 要件

- パス: `/gallery`
- 月別グリッド表示（3列、正方形サムネイル）
- スクロール連続表示（今月→過去へ月セクションが縦に並ぶ）
- 写真がない月はスキップ
- 写真タップで拡大モーダル表示
  - 拡大写真
  - 日付
  - テキスト（ログ本文）
  - 気分スタンプ
- 複数子供の場合は全員まとめて表示
  - 2人以上登録時は写真に子供バッジを表示
- 写真が1枚もない場合は空状態メッセージを表示

### 2. 通信を記録ページに統合

ナビ枠を確保するため、通信（週次・月次）への導線を記録ページに統合する。

#### 要件

- `/logs` ページにタブ切り替えを追加（記録 / 週次通信 / 月次まとめ）
- 既存の通信詳細ページ（`/weekly/[id]`, `/weekly/monthly/[id]`）はそのまま維持
- ナビから「通信」を削除

### 3. ナビゲーション構成の変更

#### 変更後のナビ（5項目）

| # | ラベル | パス | アイコン |
|---|--------|------|---------|
| 1 | 今日 | `/` | Home |
| 2 | カレンダー | `/calendar` | Calendar |
| 3 | 記録 | `/logs` | BookOpen |
| 4 | 写真 | `/gallery` | Image |
| 5 | 家族 | `/family` | Users |

#### 設定の導線

- ナビから「設定」を削除
- PC版: ヘッダー右端に歯車アイコンとして配置
- スマホ版: ヘッダー右端に歯車アイコンとして配置（ボトムバーからは削除）

## 将来の拡張（今回は実装しない）

- 統計ダッシュボード追加時: 「家族」をナビ外（設定に統合）へ移動し、「統計」をナビに追加
- テンプレート / クイック記録: v2 機能完了後に検討

## 受け入れ条件

- [ ] `/gallery` で写真が月別グリッドで表示される
- [ ] 写真タップで拡大モーダル（写真 + ログ情報）が表示される
- [ ] `/logs` で記録・週次通信・月次まとめがタブ切り替えできる
- [ ] ナビが5項目（今日・カレンダー・記録・写真・家族）になっている
- [ ] 設定がナビ外（ヘッダーアイコン）からアクセスできる
- [ ] スマホ版・PC版ともに正常に動作する
- [ ] 写真が0枚の場合に適切な空状態が表示される
- [ ] 複数子供の写真が全員まとめて表示される（2人以上で子供バッジ付き）
- [ ] lint / type-check / test がすべてパスする
