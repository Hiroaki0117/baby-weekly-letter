# 成長タイムライン - 要求定義

## 概要

子供の「初めて○○した」マイルストーンを時系列で表示する機能。週次通信生成時にAIが自動抽出するほか、ユーザーが手動で追加・編集できるハイブリッド方式。

## ユーザーストーリー

> 育児中の親として、子供の「初めて○○した」をまとめて見たい。
> それにより、成長の節目を一目で振り返りたい。

## 機能要件

### 1. マイルストーンのデータ構造

各マイルストーンは以下の情報を持つ。

| フィールド | 必須 | 説明 |
|-----------|------|------|
| タイトル | ○ | 例: 「初めて寝返りした」「初めてパパと言った」 |
| 日付 | ○ | マイルストーンが発生した日付 |
| カテゴリ | ○ | 運動 / ことば / 食事 / 生活習慣 / その他 |
| メモ | - | 補足情報（AI抽出の場合は元ログの要約） |
| ソース | ○ | AI自動抽出 / 手動追加 |

### 2. AI自動抽出

- **タイミング**: 週次通信生成時に、その週のログからマイルストーンを検出する
- **保存方式**: 自動保存（ユーザーの確認なしにDBへ保存）。ただしAI抽出結果は誤検出の可能性があるため、ユーザーが後から編集・削除できる
- **通知方式**: 週次通信の生成結果画面で「○件のマイルストーンを検出しました」と表示する
- **抽出対象**: 「初めて○○した」「できるようになった」など成長の節目と判断できるエピソード
- **カテゴリ付与**: AIが内容から適切なカテゴリを自動判定する

### 3. 手動追加・編集

- **配置場所**: タイムライン表示の上部に「追加」ボタンを設置
- **追加フォーム**: タイトル（必須）、日付（必須）、カテゴリ（必須・セレクト）、メモ（任意）
- **編集**: AI抽出・手動追加ともに編集可能
- **削除**: AI抽出・手動追加ともに削除可能

### 4. タイムライン表示

- **配置場所**: 統計ページの成長タブ内
- **表示形式**: 時系列順（新しい順）のタイムライン形式
- **カテゴリフィルタ**: カテゴリで絞り込み可能
- **カテゴリ色分け**: カテゴリごとに異なるアイコン・カラーで識別しやすくする

### 5. カテゴリ一覧

| カテゴリ | 英語キー | 例 |
|---------|---------|-----|
| 運動 | motor | 寝返り、ハイハイ、つかまり立ち |
| ことば | language | 初めてパパと言った、二語文 |
| 食事 | eating | 離乳食開始、手づかみ食べ |
| 生活習慣 | lifestyle | 一人で着替え、トイレトレーニング |
| その他 | other | 初めての旅行、初めてのプール |

## 受け入れ条件

- [ ] 統計ページの成長タブ内にマイルストーンタイムラインが表示される
- [ ] タイムラインにマイルストーンを手動追加できる（タイトル・日付・カテゴリ必須）
- [ ] マイルストーンを編集・削除できる
- [ ] カテゴリでフィルタリングできる
- [ ] 週次通信生成時にAIがマイルストーンを自動抽出し、DBに保存する
- [ ] 生成結果画面で抽出されたマイルストーン数が通知される
- [ ] AI抽出マイルストーンにも適切なカテゴリが付与される
- [ ] 子供ごとにマイルストーンが管理される

## 制約事項

- マイルストーンは子供（child）単位で管理する
- AI抽出はベストエフォート（検出漏れは手動追加で補完）
- 同じ内容の重複抽出を可能な限り防ぐ（日付＋類似タイトルでチェック）
