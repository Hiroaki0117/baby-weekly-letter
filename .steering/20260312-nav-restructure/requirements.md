# 要求: フッターナビ再構成（写真→記録タブ移動、統計→フッター昇格）

## 背景

- 統計ページは日常的に使うが、現在は「その他」メニュー内に隠れておりアクセスが悪い
- 写真ギャラリーは記録・アルバムと同カテゴリの情報であり、記録ページのタブに統合するのが自然
- フッター5枠の1つを写真→統計に入れ替えることで、日常操作の導線を改善する

## 変更内容

1. **フッターナビ**: 写真(`/gallery`)を統計(`/stats`)に差し替え
   - 変更前: 今日 / カレンダー / 記録 / **写真** / その他(統計・家族・設定)
   - 変更後: 今日 / カレンダー / 記録 / **統計** / その他(家族・設定)

2. **記録ページのタブ**: 大項目タブに「写真」を追加
   - 変更前: 📝 記録 | 📚 アルバム
   - 変更後: 📝 記録 | 📸 写真 | 📚 アルバム

3. **記録ページ内の写真タブ**: 既存の GalleryPage のロジックを記録ページ内に組み込む

## 受け入れ条件

- フッターに統計アイコンが表示され、タップで `/stats` に遷移する
- 「その他」メニューから統計が消え、家族・設定のみ残る
- 記録ページに「写真」タブが追加され、タップで写真ギャラリーが表示される
- `/gallery` パスへの直接アクセスは記録ページの写真タブにリダイレクトする
- 既存の写真ギャラリー機能（月別グリッド、モーダル表示、遅延読み込み）がすべて動作する
