# 設計: モバイルナビゲーション「その他」メニュー追加

## 実装アプローチ

ボトムバーの5項目目を「その他」ボタンに変更し、タップでオーバーレイメニューを表示する。メニューはボトムバーの直上にポップアップするシンプルなカード形式とする。

## 変更するコンポーネント

### 1. `src/components/layout/bottom-nav.tsx`（大幅変更）

現在の `navItems` 配列から統計を除去し、5番目を「その他」ボタンに変更。

**変更内容:**

- `navItems` を4項目に変更（今日・カレンダー・記録・写真）
- 5番目に「その他」ボタンを追加（`MoreHorizontal` アイコン）
- `useState` で「その他」メニューの開閉を管理
- メニュー展開時にオーバーレイ（半透明背景）を表示し、外側タップで閉じる
- メニュー内に4項目を表示：統計・家族・設定・ログアウト
- ログアウト処理は `supabase.auth.signOut()` を呼び出し
- `/stats`, `/family`, `/settings` のいずれかがアクティブな場合、「その他」をアクティブ表示

**メニューUI:**

```
┌──────────────────────────┐
│  📊 統計                  │
│  👥 家族                  │
│  ⚙️  設定                  │
│  ──────────────────────  │
│  🚪 ログアウト            │
└──────────────────────────┘
┌──────────────────────────┐
│ 今日 | カレンダー | 記録 | 写真 | その他 │
└──────────────────────────┘
```

- メニューはボトムバーの直上に表示（`bottom: 100%`）
- 右寄せで表示（「その他」ボタンの上に配置）
- 角丸カード + シャドウで浮かせたデザイン
- ログアウトは区切り線で分離

### 2. `src/components/layout/header.tsx`（変更なし）

デスクトップ版は現状維持。

### 3. `src/components/layout/nav.tsx`（変更なし）

デスクトップ版は現状維持。

なし。

- 他のコンポーネント・ページへの影響なし
- デスクトップ版は変更なし
