# 睡眠計測状態の家族間共有

## 背景

現在、睡眠タイマーの計測中状態は `localStorage` にのみ保存されているため、開始ボタンを押した本人のブラウザでしか「記録中」が表示されない。家族の他のメンバーが別の端末で画面を開いても計測中であることがわからず、終了操作もできない。

## 要件

1. 睡眠タイマーを開始すると、家族全員の画面に「記録中」が表示される
2. 開始した本人以外の家族メンバーも終了操作が可能
3. 終了時に `sleep_records` に確定レコードが作成される（既存動作と同じ）
4. タイマーは子供ごとに1つまで（同じ子供で複数タイマーは不可）

## 受け入れ条件

- [ ] Supabaseに `sleep_tracking` テーブルを作成し、計測中状態をサーバー側で管理
- [ ] タイマー開始時に `sleep_tracking` にレコードをinsert
- [ ] 家族ページを開いた際、アクティブな `sleep_tracking` レコードを取得して「記録中」を表示
- [ ] 家族メンバーの誰でも終了操作ができる
- [ ] 終了時に `sleep_tracking` レコードを削除し、`sleep_records` に確定レコードを作成
- [ ] 取消時に `sleep_tracking` レコードを削除
- [ ] localStorageへの保存は廃止し、サーバー側のみで状態管理

## 制約事項

- リアルタイム同期（Supabase Realtime）は不要。ページ読み込み時に最新状態を取得すれば十分
- RLSポリシーで同一家族のみアクセス可能にする
